## Falhas e retrabalho

- `git archive` como entrada (`1561e4d`) deixava um `.gitattributes` rastreado esconder arquivos (export-ignore, working-tree-encoding): pego pelo @qa, trocado por blobs brutos. Lição: conteúdo para varredura sai de `git cat-file`, nunca de comando que aplica atributos.
- O teste de regressão falhou de início: com `git add -A`, o git releu um arquivo "racily clean" com o atributo novo e tentou convertê-lo de UTF-16; o teste passou a adicionar só os arquivos novos.
- Importar `IMAGEM` de `scripts/semgrep/rodar.mjs` executou o script (efeito colateral na importação); a constante foi copiada.
- A primeira versão do gravador de blobs (`1996e67`) ficou com a expressão `[\:]` em vez de `[\\:]` (a barra invertida se perdeu) ao ser editada por Python no shell: a mesma lição da E2-3 (expressão com `\` se edita com Edit). A trava de caminho resolvido e a gravação sem sobrescrever entraram como segunda defesa.
- Docker Desktop estava desligado no início; foi ligado para a prova sem rede.
